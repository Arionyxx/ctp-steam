| Frappé | Dark | Evening use, moderate lighting | Medium-High |

| Mocha | Dark | Night use, minimal lighting | Very High |

## Color Usage Guidelines

### Backgrounds
- **Base** - Main application background
- **Mantle** - Top/bottom bars, sidebars
- **Crust** - Deepest backgrounds, panels

### Surfaces
- **Surface0** - Input fields, dropdowns
- **Surface1** - Hover states on lists
- **Surface2** - Secondary UI elements

### Text
- **Text** - Primary content, headings
- **Subtext1** - Secondary content
- **Subtext0** - Muted text, placeholders

### Overlays
- **Overlay0-2** - Icons, dividers, borders

### Accents
- **Blue** - Primary actions, links, focus
- **Green** - Success, online status, play
- **Yellow** - Warnings, away status
- **Red** - Errors, destructive actions
- **Sky** - Information, updates

## Accessibility Notes

1. **Normal text** requires 4.5:1 contrast (all flavors exceed this)
2. **Large text** (18pt+) requires 3:1 contrast
3. **UI components** require 3:1 contrast against adjacent colors
4. **Focus indicators** use accent colors with sufficient contrast
5. **Link colors** meet contrast requirements in all states

## Color Blindness Considerations

The Catppuccin palette is designed with color blindness in mind:

- **Protanopia/Deuteranopia** (Red-Green): Blue accents provide clear visual distinction
- **Tritanopia** (Blue-Yellow): Multiple accent colors available
- **Achromatopsia** (Total): High contrast ratios ensure usability

## Customization Tips

1. **Accent colors** can be changed to any Catppuccin color
2. Maintain **similar lightness** when substituting colors
3. Test **contrast ratios** when customizing text colors
4. Use **HSL values** for easier color adjustments
5. Keep **hover states** lighter/darker than base states
